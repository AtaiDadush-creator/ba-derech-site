# מה מחכה לעתיי

האתר הזמני חי: https://ataidadush-creator.github.io/ba-derech-site/ (לא נסרק בגוגל עד המעבר לדומיין).
כל שינוי שנדחף ל-main עובר בדיקות אוטומטיות ב-GitHub (טלפון, טאבלט, מחשב, Chrome ו-Safari, נגישות, Lighthouse), ורק אם הכול עובר הוא עולה לאוויר.

סדר לפי חשיבות. כל דבר: מה לעשות, ומה כתוב באתר עד אז.

## 1. אישור להעביר את ba-derech.com לאתר (2 דקות)
כשתגיד "מאשר", אני עושה את זה ב-Chrome בחשבון ה-Squarespace שלך:
- ב-DNS של ba-derech.com: ארבע רשומות A לשורש הדומיין, 185.199.108.153, 185.199.109.153, 185.199.110.153, 185.199.111.153, במקום רשומות ה-Squarespace. ו-www כ-CNAME ל-ataidadush-creator.github.io.
- לא נוגעים ב-MX (smtp.google.com) וב-SPF (TXT). המייל ממשיך לעבוד.
- בריפו: קובץ src/CNAME עם ba-derech.com, ואז הפעלת HTTPS בהגדרות GitHub Pages. ההחלפה לוקחת בין כמה דקות לשעה.
- אם תעדיף לעשות לבד: Squarespace, Domains, ba-derech.com, DNS Settings, ושם את מה שכתוב למעלה.

## 2. הפרטים החסרים
מולאו ב-27/10 (src/owner.json). לבקשת עתיי לא מצוינים באתר: תנאי יציאה מוקדמת, הקלטות, שעות מענה של המורה.

## 3. הטופס, ציטוטים ומורים
- **כתובת הטופס**: עד שתהיה, הטופס בעמוד "צרו קשר" פותח וואטסאפ עם הפרטים. כדי שהפרטים יגיעו ישר לגיליון ולמייל: פורסים את הסקריפט לפי docs/LEADS-SETUP.md (כ-15 דקות: גיליון חדש "פניות מהאתר", מדביקים את הקוד, מריצים setup, פריסה כאפליקציית אינטרנט לכל אחד), ושולחים ל-Claude את הכתובת שנגמרת ב-/exec. היא נכנסת ל-src/owner.json בשדה leadsEndpoint.
- **ציטוטים (לפחות 3 של הורים)**: הטקסט כפי שנכתב, התווית (למשל "אבא של תלמיד בכיתה ז׳"), חודש ושנה, מאיפה (וואטסאפ, מייל, טופס), והאם ניתן משהו בתמורה. ההסכמה בכתב, צילום מסך שלה ושם ההורה נשמרים בגיליון הפרטי "הסכמות לציטוטים" לפי ref. בקשת ההסכמה, לשלוח כמו שהיא: `אפשר לפרסם באתר את מה שכתבת, בלי שם, בתור ״אמא של תלמיד בכיתה ח׳״? אפשר לבקש להסיר בכל זמן.`
- **כרטיסי מורים (לפחות 3)**: לכל מורה שם כפי שירצה, תפקיד, כיתות, משפט אחד במילים שלו, ותמונה ריבועית אם ירצה. בקשת ההסכמה: `אפשר להציג באתר כרטיס עם השם שלך, הכיתות שאתה מלמד, המשפט הזה והתמונה? אפשר לבקש להסיר בכל זמן.`
- עד שיש 3, הסקשן לא מופיע באתר בכלל (ולא כתוב "בקרוב").
- לא מפרסמים צילומי מסך של וואטסאפ, שמות או פנים של ילדים, ולא ציון "לפני ואחרי".

- "מומחה מיומן במציאת הפער": באתר כתוב עכשיו "מי שמוביל אצלנו את השיבוץ לקבוצות" (הניסוח החלופי מ-docs/LEGAL.md). אם יש לניסוח הקודם בסיס שאפשר להראות, אפשר להחזיר אותו.
- אישורי משטרה למורים: לוודא שיש לכל מורה לפני שיעור ראשון.
- ba-derech.co.il פנוי. רכישה (כ-50 עד 80 ₪ לשנה אצל רשם ישראלי) שומרת על השם, ואפשר להפנות אותו לאתר.
